게임 제작 인터뷰 분석

벽돌깨기 요청에서 확정된 규칙과 구현 중에 정한 값을 살펴보세요.

조작과 점수에 어떤 요구가 있었나요?

실제 요청 “방향키로 패들을 움직이고, 화면 위에 점수 표시.”

설계 결정 좌우 방향키로 패들을 움직이고, 벽돌 하나를 맞힐 때마다 점수판을 10점씩 올려요. 보라색 게임판 위쪽에 점수를 배치했어요.

더 물어볼 질문 “휴대폰에서도 플레이할까요?” 이 사이트의 게임에는 화면 버튼도 넣었어요.

벽돌 수와 색상은 어떻게 정했나요?

실제 요청 벽돌 줄 수와 색 테마는 각각 입력칸으로 남아 있었어요.

첫 버전의 가정 5줄과 남색·민트·보라를 사용했어요. 브로브로에서는 5줄을 유지하고 벽돌 색을 아케이드 테마에 맞췄어요.

더 물어볼 질문 “한 판을 가볍게 끝내고 싶나요, 더 오래 도전하고 싶나요?” 답에 따라 줄 수와 공 속도를 조절할 수 있어요.

공을 놓친 뒤 어떤 일이 일어나나요?

실제 요청 공을 놓치면 “다시 시작” 버튼을 보여 줘요.

설계 결정 공이 화면 아래로 넘어가면 게임을 멈춰요. 다시 시작하면 점수를 0으로 바꾸고 벽돌과 공의 위치를 되돌려요.

확인 방법 가만히 두고 공이 떨어질 때까지 기다린 뒤, “다시 시작”을 눌러 점수와 벽돌을 확인해요.

내 게임을 만들기 전에 물어볼 질문

  • 첫 10초 플레이어가 제일 먼저 무엇을 하고, 조작은 어떻게 익힐까요?
  • 핵심 규칙 어떤 행동에 점수나 보상이 붙고, 언제 한 판이 끝나나요?
  • 미정 항목 난이도·화면 크기·색처럼 정하지 않은 항목 중 어디까지 맡겨도 되나요?
  • 검수 성공, 실패, 다시 시작 때 각각 어떤 화면이 나오면 통과인가요?
