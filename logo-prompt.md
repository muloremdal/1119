# 브로브로 로고 제작 프롬프트

## 사용한 프롬프트

```text
Use case: logo-brand. Design one original logo mark for 브로브로 (BroBro), a black-and-violet retro arcade resource site. Exactly two clearly recognizable standalone upright arcade cabinets are the two friendly characters, side by side, leaning into a warm shoulder hug. Give each cabinet one simple inward cartoon arm that drapes over the other cabinet's outer shoulder so the gesture reads instantly, with clearly separated silhouettes and two distinct cabinet bodies. Each has a CRT screen, joystick and a pair of buttons. Subtle smile on each CRT. Bold chunky pixel-inspired geometric forms, black-violet body, bright violet and lilac accent outlines for a near-black website, crisp flat colors, high contrast. Centered tight square composition with small safe padding, transparent background, clean alpha. Mark only, no text, lettering, borders, scene, third character, gradients or glow. Original cabinet design with no existing game branding.
```

## 이미지 적용

팀 이름 ‘브로브로’는 페이지에서 글자로 표시하고, 두 아케이드 게임기는 투명 배경의 심볼로 쓴다. 이미지 경로는 `images/logo.png`다.
